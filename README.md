# Конвейер розлива — 3D-симуляция с машинным зрением

Интерактивная 3D-симуляция линии розлива воды: конвейер, камера контроля качества и пневматический сбиватель брака.

**Открыть симуляцию:** https://constantintesla.github.io/conveyor-simulator/

## Что внутри

- **Конвейер розлива** — 3D-сцена на Three.js (подгружается с CDN), лента с текстурой, рейки, ролики, лотки «БРАК» и «ГОДНЫЕ».
- **Три типа брака** — недолив, чужая крышка (другой цвет), кривая этикетка (повёрнута на 12–35°).
- **Камера CAM-01 с машинным зрением** — у камеры собственный рендер-кадр 320×240, распознавание идёт по пикселям кадра, а не по заранее известным флагам:
  - недолив — сканирование силуэта бутылки сверху вниз в поисках уровня воды;
  - крышка — усреднение цвета в области крышки;
  - этикетка — детекция полосы по колонкам кадра и наклон методом наименьших квадратов.
- **Сбиватель** — пневматический толкатель, сшибает отбракованную бутылку в лоток «БРАК» (кувыркается по физике), годные едут до приёмника.
- **Контроль качества зрения** — счётчики «Промахи камеры» и «Ложные срабатывания»: симуляция измеряет точность детекторов, а не только сценарий линии.
- **Живой оверлей** — поверх кадра камеры рисуются рамка объекта, найденный уровень воды, рамка крышки и линия наклона этикетки с градусами.

## Управление

| Действие | Как |
|---|---|
| Вращать камеру | левая кнопка мыши |
| Зум | колесо |
| Панорама | правая кнопка |
| Вернуть вид по умолчанию | кнопка «Камера» |
| Скорость ленты | слайдер «Скорость» (0.3–2.6 м/с) |
| Доля брака | слайдер «Доля брака» |
| Типы брака | чекбоксы (недолив / крышка / этикетка) |
| Пауза / сброс | кнопки панели «Параметры линии» |

## Запуск локально

Один файл `index.html` — достаточно открыть его в браузере. Нужен доступ к `cdn.jsdelivr.net`, откуда подгружается Three.js (при отсутствии сети показывается заглушка).
